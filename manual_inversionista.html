1. Inicio de Sesion

El sistema utiliza autenticacion JWT (JSON Web Token). Cada usuario pertenece a una empresa (multi-tenant) y tiene un rol asignado.

Roles de Usuario

RolPermisos
adminAcceso total: CRUD completo, configuracion, reportes, gestion de usuarios
usuarioCrear y editar registros, consultar reportes
readonlySolo lectura: consultas y reportes unicamente
💡
Seguridad multi-tenant: Cada stored procedure recibe el empresa_id del token JWT, garantizando aislamiento total de datos entre empresas.

DUA - Declaracion Unica de Aduanas

Documento clave para tributos de importacion. El sistema calcula automaticamente todos los tributos basado en las formulas de SUNAT.

Formulas de Calculo (SUNAT)

// Base CIF = FOB + Flete + Seguro // Tributos Ad Valorem = CIF × tasa_partida (ej: 6%) Base IGV = CIF + Ad Valorem IGV = Base IGV × 16% IPM = Base IGV × 2% // Percepcion Base Perc = CIF + Ad Valorem + IGV + IPM Percepcion = Base Perc × 3.5%

9. Prorrateo y Costeo

El corazon del sistema. Distribuye todos los costos entre los items de las OCs para obtener el costo landed (costo real) de cada producto.

Proceso de 3 Pasos

1
Seleccionar Importacion
Elija la importacion a costear. El sistema muestra OCs asociadas y totales.
2
Calcular Prorrateo
Seleccione metodo de distribucion. El sistema genera la propuesta sin aplicarla.
3
Aplicar Prorrateo
Revise resultados y aplique para guardar costos prorrateados en cada item.

4 Metodos de Distribucion

MetodoDistribuye segunCuando usar
valor_fobProporcion del valor FOBRecomendado Metodo mas comun
pesoPeso (kg) de cada itemFlete cobrado por peso
volumenVolumen (m3) de cada itemFlete cobrado por volumen
cantidadCantidad de unidadesItems homogeneos

13. Flujo Completo de Importacion

⚙
1. Configuracion Inicial
Registrar proveedores, productos, almacenes
🛒
2. Crear Orden de Compra
Seleccionar proveedor, agregar items, precio FOB
⚓
3. Crear Importacion
Datos de embarque: BL, container, via transporte
📋
4. Asociar OCs a Importacion
Vincular ordenes de compra al embarque
🧾
5. Registrar Gastos
Flete, seguro, agente, almacenaje, transporte local
📄
6. Registrar DUA + Documentos
Numero DUA, items, calculo automatico de tributos
🧮
7. Ejecutar Prorrateo
Distribuir costos entre items por metodo elegido

8. Revisar Ficha de Costeo
Verificar costo landed por producto
⬇
9. Ingreso a Almacen
Crear movimiento de ingreso con costo landed

Verificar stock valorizado formato SUNAT

15. Glosario

TerminoDefinicion
FOBFree On Board - Precio de la mercancia puesta en el puerto de origen
CIFCost, Insurance & Freight - FOB + Flete + Seguro
DUADeclaracion Unica de Aduanas - Documento de despacho aduanero peruano
Ad ValoremArancel de importacion calculado sobre el CIF segun partida arancelaria
IGVImpuesto General a las Ventas (18% = 16% IGV + 2% IPM)
IPMImpuesto de Promocion Municipal (2%)
PercepcionPago adelantado de IGV (3.5% sobre CIF + tributos)
IncotermTermino de comercio internacional (FOB, CIF, EXW, CFR, etc.)
BLBill of Lading - Conocimiento de embarque maritimo
Partida ArancelariaCodigo HS de 10 digitos que clasifica la mercancia para tributos
ProrrateoDistribucion proporcional de costos entre items importados
Costo LandedCosto total real: FOB + todos los gastos prorrateados
KardexRegistro de inventario permanente valorizado (requerido por SUNAT)
TLCTratado de Libre Comercio - Puede reducir/eliminar el Ad Valorem
