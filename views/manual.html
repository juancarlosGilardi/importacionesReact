Introducción al Sistema

El Sistema de Costeo de Importaciones es una solución integral diseñada para gestionar y controlar todos los procesos relacionados con la importación de mercancías, desde la orden de compra hasta el ingreso a almacén.

Objetivo Principal: Automatizar el cálculo del costo real de importación mediante el prorrateo de gastos a los productos importados.
📋

Gestión Completa

Administra todo el ciclo de importación en un solo lugar.

💰

Control de Costos

Calcula automáticamente el costo real de importación.

📊

Reportes Avanzados

Genera reportes detallados para análisis y toma de decisiones.

Módulo: Órdenes de Compra

Gestión completa de órdenes de compra internacionales (PO).

Crear Nueva Orden

Acceda a Órdenes → Nueva Orden y complete todos los campos requeridos:

  • Número PO: Identificador único de la orden
  • Proveedor: Seleccione del catálogo de proveedores
  • Fecha Orden: Fecha de emisión de la orden
  • Incoterm: Términos de entrega (FOB, CIF, etc.)
  • Items: Agregue productos con cantidades y precios

Estados de la Orden

El sistema maneja 7 estados principales:

  1. Borrador - En preparación
  2. Confirmada - Confirmada con proveedor
  3. En Tránsito - Mercancía en camino
  4. En Aduana - Proceso de desaduanaje
  5. Prorrateado - Costos calculados
  6. En Almacén - Mercancía recibida
  7. Completada - Importación finalizada

Vista de Detalle

Cada orden tiene una vista detallada que incluye:

  • Timeline del estado actual
  • Información general y logística
  • Items de la orden
  • Facturas relacionadas
  • Gastos asociados
  • Documentos de transporte
  • Información de DUA
  • Movimientos de almacén

Módulo: Facturas XML

Registro y gestión de facturas de proveedores internacionales.

Nota: El sistema soporta subida de archivos XML para extracción automática de datos.

Registrar Factura

Para registrar una nueva factura:

  1. Acceda a Facturas → Nueva Factura
  2. Seleccione la orden de compra relacionada
  3. Ingrese el número de factura y fecha
  4. Complete los montos (subtotal, IGV, total)
  5. Verifique los items automáticamente cargados de la PO
  6. Guarde la factura

Subir XML

Para aprovechar la funcionalidad de XML:

// El sistema automáticamente extraerá: - Número de factura - Fecha de emisión - Proveedor - Items y cantidades - Montos (subtotal, impuestos, total) - Moneda

Haga clic en "Subir XML" y seleccione el archivo.

Módulo: Registro DUA

Gestión del Documento Único de Aduana y cálculo de impuestos.

Registrar DUA

Para registrar un nuevo DUA:

  • Número DUA: Número del documento
  • Fecha Registro: Fecha de registro en aduana
  • Valores: FOB, flete, seguro, CIF
  • Impuestos: Ad-valorem, IGV, IPM, otros
  • Gastos Aduaneros: Honorarios, almacenaje, etc.

Cálculo Automático

El sistema calcula automáticamente:

CIF = FOB + Flete + Seguro Ad-valorem = CIF × Tasa IGV = (CIF + Ad-valorem) × 18% IPM = (CIF + Ad-valorem) × Tasa Total Impuestos = Suma de todos los impuestos

Módulo: Prorrateo de Costos

Distribución de costos de importación a los productos.

Importante: Este módulo calcula el costo real por producto considerando todos los gastos de importación.

Métodos de Prorrateo

El sistema ofrece 4 métodos:

  1. Por Valor (FOB): Según el valor de cada producto
  2. Por Peso: Según el peso de cada producto
  3. Por Volumen: Según el volumen de cada producto
  4. Manual: Distribución manual personalizada

¿Cuál método usar? Use Por Valor para productos con valores similares, Por Peso para productos pesados, Por Volumen para productos voluminosos.

Proceso de Prorrateo

Para ejecutar el prorrateo:

1. Seleccione la orden de compra 2. Elija el método de prorrateo 3. Revise los datos cargados (FOB y gastos) 4. Calcule el prorrateo 5. Revise los resultados 6. Aplique el prorrateo al sistema

Módulo: Almacén

Registro de ingreso de mercancías al almacén.

Registrar Ingreso

Para registrar el ingreso de mercancías:

  • Movimiento: Ingreso, Transferencia, Ajuste
  • Fecha: Fecha del movimiento
  • Ubicación: Ubicación en el almacén
  • Lote: Número de lote (opcional)
  • Items: Productos recibidos
  • Cantidades: Cantidades recibidas por producto

Actualización Automática

Al registrar el ingreso, el sistema automáticamente:

  1. Actualiza el estado de la orden a "En Almacén"
  2. Actualiza el inventario de productos
  3. Registra el costo unitario prorrateado
  4. Genera reporte de ingreso

Requisitos del Sistema

  • Python: Versión 3.8 o superior
  • MySQL: Versión 5.7 o superior
  • Memoria RAM: Mínimo 4GB recomendado
  • Espacio Disco: 500MB mínimo

Instalar dependencias pip install -r requirements.txt # 4. Configurar base de datos mysql -u root -p < importaciones_costeo.sql # 5. Configurar variables cp config_importaciones.py.example config_importaciones.py # Editar config_importaciones.py con tus datos # 6. Ejecutar la aplicación python main_importaciones.py

Configuración Inicial

Después de la instalación, configure:

  1. Proveedores en el catálogo
  2. Productos del inventario
  3. Monedas y tipos de cambio
  4. Usuarios del sistema
  5. Parámetros del sistema

Flujo de Trabajo Completo

Flujo estándar para una importación:

Paso 1: Crear Orden de Compra

Registre la orden de compra internacional con todos los detalles y items.

Paso 2: Registrar Factura

Cuando reciba la factura del proveedor, regístrela en el sistema.

Paso 3: Documentos de Transporte

Registre BL/AWB y otros documentos de transporte.

Paso 4: Registrar DUA

Cuando reciba el DUA, ingréselo al sistema para cálculo de impuestos.

Paso 5: Registrar Gastos

Registre todos los gastos adicionales de la importación.

Paso 6: Prorrateo de Costos

Distribuya los costos a los productos para obtener costo real.

Paso 7: Ingreso a Almacén

Registre el ingreso de la mercancía al almacén.

Paso 8: Generar Reportes

Genere reportes para análisis y contabilización.

Preguntas Frecuentes

¿Cómo calcula el sistema el costo real?

El sistema suma todos los costos (FOB + flete + seguro + impuestos + gastos) y los distribuye a los productos según el método de prorrateo seleccionado.

¿Puedo importar facturas XML?

Sí, el sistema tiene funcionalidad para subir archivos XML y extraer automáticamente los datos de la factura.

¿Qué métodos de prorrateo son más comunes?

El método más utilizado es "Por Valor (FOB)", pero depende del tipo de productos. Para productos pesados use "Por Peso", para voluminosos "Por Volumen".

¿Cómo actualizo el estado de una orden?

El estado se actualiza automáticamente según las acciones que realice (registrar DUA, ingresar a almacén). También puede cambiarlo manualmente desde el formulario de edición.

¿Puedo exportar los reportes?

Sí, todos los reportes pueden exportarse a Excel y PDF desde el módulo de reportes.

¿Cómo configuro nuevos tipos de gastos?

Los tipos de gastos se configuran en la tabla expense_types_ui de la base de datos. Puede agregar nuevos tipos según sus necesidades.
